## PreflightOps

**Category:** SRE / DevOps / Platform Engineering
**Status:** Active
**Repository:** https://github.com/pedroluna-gh/preflightops

PreflightOps is a pre-deployment risk assessment tool for engineering teams that need better production change discipline.

It helps reviewers detect operational gaps before shipping risky changes.

### Problem

Many incidents are caused by changes that looked acceptable during review but had weak rollback plans, missing monitoring, unclear ownership, incomplete runbooks or risky infrastructure signals.

### Solution

PreflightOps gives teams a structured way to evaluate a change before it reaches production.

It produces a risk score, risk level, recommendation and concrete findings.

### Useful for

* SRE teams
* Platform Engineering teams
* DevOps teams
* Technical pre-CAB reviews
* Pull-request change gates
* Production readiness reviews

### Key capabilities

* Service catalog evaluation
* Change request assessment
* Rollback readiness checks
* Monitoring and validation checks
* Terraform risk signal detection
* Kubernetes risk signal detection
* Markdown and JSON reports
* CLI usage
* Streamlit web UI
* GitHub Action integration

### Why it matters

The value is not only the score.

The value is making hidden operational assumptions visible before a risky change is approved.
